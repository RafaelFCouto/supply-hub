# Frontend Design System

Current visual direction for Supply Hub:

- Theme: industrial editorial
- Mood: operational, sharp, confident
- Primary accent: rust orange
- Surface palette: graphite, sand, chalk
- Typography:
  - Display: `Space Grotesk`
  - Reading/UI accent: `Source Serif 4`
- Shape language:
  - large panel radii
  - thin borders
  - soft shadows with low blur
- Interaction:
  - restrained motion
  - focus on clarity, contrast and hierarchy

Rules for next screens:

- Keep the same color tokens and typography.
- Prefer split layouts, framed panels and restrained ornament instead of generic card grids.
- Use the rust accent sparingly for actions and status emphasis.
- Avoid introducing a second visual theme.
